# SABLE Website Brand Audit

Source: https://sable-fashion-store.netlify.app/ and its public CSS/image assets.

## Visual tokens

- Bone background: `#EFEDE8`
- Ink: `#101010`
- Mid grey: `#8A8781`
- Gold accent: `#C5A059`
- Supporting dark/grey values observed: `#4A4741`, `#54514C`, and `#DCD9D3`
- Primary website font: `Archivo`, loaded from Google Fonts.
- Editorial product-detail headings also reference `Bodoni MT, Didot, serif`; the report keeps the main body in Archivo and uses editorial spacing/wordmark treatment.

## Composition

The live website uses a warm off-white field, oversized black SABLE wordmark, thin black/gold hairlines, small uppercase navigation labels, generous whitespace, and monochrome fashion editorial photography. The hero asset is an isolated model in a charcoal overcoat, with “Fashion that moves with you” and “Autumn collection 2026” annotations.

# 🎥 TEAM KAIZO - APBOT DEMONSTRATION VIDEO

## Overview
This directory contains the official project demonstration video for **ApBot** (E-Commerce AI Shopping Assistant), submitted by **Team Kaizo** for the **Aptech Contest-AZM (Software Requirements Specification - ApBot)** evaluation.

---

## 📹 Video File Details
- **File Name**: `TEAM-KAIZO.MOV`
- **File Size**: ~182.8 MB
- **Format**: QuickTime Movie (.MOV / H.264)
- **Resolution**: High Definition (1080p)
- **Duration**: Complete walkthrough of ApBot UI, natural language processing, product catalog search, order tracking, and checkout integration.

---

## 📑 Content Covered in Demonstration Video
1. **Introduction & SRS Alignment**: Overview of ApBot AI E-Commerce Assistant built with TensorFlow/Keras and React.
2. **Natural Language Conversations**: Live demonstration of ApBot responding to customer queries, greetings, product recommendations, and typo correction.
3. **E-Commerce Operations**: Searching products, viewing product details, adding items to cart & wishlist, and mock payment checkout.
4. **Order & Report Tracking**: Tracking order IDs (`SBL-12345`) and issue report IDs (`SBL-REP-12345`) in real-time.
5. **Backend & AI Architecture**: Demonstration of Node.js Express server (Port 5000), Python Flask AI microservice (Port 5001), and MongoDB database integration.
